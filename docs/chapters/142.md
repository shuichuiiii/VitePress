# 第142章 番外八:念桃

尚之桃高一那年班级元旦联欢会,文艺委员组织大家表演节目。那一年的原则是每个人都要有节目，哪怕你演一棵树都行。
　　班级里文艺生很多，唱歌跳舞的节目立即满了。班主任就说也别都唱歌跳舞了,显得咱们班才艺匮乏。于是有男同学连夜去学变戏法,尚之桃和贺云彼此看看，突然都没了主意。
　　于是自荐去给别的节目演一棵树或者举牌，但教室太小了，唱歌跳舞根本没地方再站一棵树。
　　最后尚之桃对文艺委员说：“要不我表演一个写字吧？贺云表演研墨。”
　　“行！写完了裱起来挂在教室后面，非常有意义。”
　　尚之桃时候遇到的同学都挺好玩,班级里也有刺儿头，但对尚之桃都好。大概因为尚之桃总是真心祝福别人。
　　尚之桃和贺云真的表演了写字研墨,在教室有一张小桌子,尚之桃她们在联欢会开到一半的时候开始表演。主持人介绍：“接下来尚之桃贺云同步表演法,其他节目也将进行，最后展示法。”
　　各个班都在搞联欢会,尚之桃她们班有墨水香，校领导们一进门就闻到了，笑道：“法也能表演,挺好啊。”
　　就这么过去了。
　　尚之桃和贺云舒了一口气,那天放学早,两个人收拾好文具出教室，看到高年级的男同学，看到尚之桃就互相问：“这是那个表演写字的同学？”
　　成是了。
　　再过两天，有人在走廊塞给尚之桃一封情,她问：“给谁的啊？”
　　“不知道！”男同学红着脸走了,尚之桃也不知道该给谁,反正不是给自己的,就想着再遇到那个男同学问清楚。可她忘了男同学长什么样了，这事就这么算了。挺迟钝的。
　　尚之桃一直以为她学生时代只被辛照洲喜欢过，因为辛照洲的喜欢太明显了。他第一次见到尚之桃就对同班同学说：“以后阶梯教室上大课，都帮我抢尚之桃旁边的位置。”
　　“还有啊，食堂打饭帮我站她身后。”
　　“图馆里她对面的位置帮我占住。”
　　“无论在哪儿看到她都第一时间告诉我。”
　　阵仗太大了，起初女同学跟尚之桃说：“那个班草辛照洲喜欢你。”
　　“他喜欢我干什么？”尚之桃并不肯相信。她只是觉得巧合了一点，辛照洲在图馆坐她对面，打饭站她身后，再过一两周，上大课的时候，女同学们都会在她一侧留位置，那个位置很快坐着辛照洲。
　　她懵懂着看到辛照洲站在她面前，红着脸对她说：“尚之桃，我喜欢你。”
　　在南京的冬天里，他怀里揣着鲜花，送给你。
　　原来他真的喜欢我啊。
　　她真的是很钝感的人，要是真的偏爱她才能感觉得到。现在的她能够感受到栾念爱她，因为他对她的偏爱太明显了。
　　尚之桃睁开眼的时候天已经大亮了。
　　她好像很久没有睡过这么好的觉了。拉开窗帘，看到外面的天昏昏暗暗，她在窗内就能感觉到外面的潮湿。要下雨了。
　　栾念手臂放在眼睛上：“尚之桃！窗帘拉上！”
　　“不！”
　　栾念跳下床扯上窗帘，抱起她丢回床上：“闭眼！睡觉！”
　　将她锁在胸前，语气并不特别好：“快点！”
　　“哦。”
　　尚之桃闭上眼睛，她也确实是想睡回笼觉。手揽住栾念腰身，腿在他腿间寻个位置，又睡了。她每个星期最好的两天觉就是栾念在身边的时候，栾念这个霸道精不允许她早起，只要他在，他们就要睡到日上三竿。
　　这一觉睡到了午后。
　　他们睁开眼的时候外面真的下起了雨，倾城大雨。
　　“天气预报说要下两三天，周一早上的飞机要延误了。”
　　“周一是全天会议，我可以远程参加，周二走吧。”
　　大家都在这两年培养了远程办公协作的习惯和能力。lumi对尚之桃说：“真希望你能每周日把你的老公我的倔驴凌美中国的掌门人按时传送回北京。”
　　“为什么啊？”
　　“因为他不在公司的时候我们日子更难过了。”
　　栾念远程办公受到的干扰少，脑子就愈发好用，一个部门一个部门过工作，过完了保证一大堆todo。他在公司呢，见这个见那个，todo少了，日子就能好过点。
　　两个人躺在床上看外面的雨，栾念放了他的“慵懒”歌单，两个人都不讲话。尚之桃手指在栾念下巴上划，他脸上冒出的胡茬扎的她心里有点痒。
　　尚之桃手机响了，她顺手拿起看了一眼，竟然是辛照洲：“最近怎么样？听说你结婚了。”
　　尚之桃看了一眼栾念，将手机丢到一旁，不想当着栾念的面回辛照洲消息，因为栾念是个“小气鬼”。
　　栾念不是完美爱人，他的缺点和优点一样多，占有欲是他最大的缺点，尚之桃当然知道。单单是“辛照洲”这个名字就够他生气的了。
　　“不回？”
　　“哈？”
　　“你不回消息？”栾念问她，他都不用故意看就知道她心虚。
　　“…不是什么着急的事儿。”
　　“辛照洲？”
　　“？”
　　尚之桃打开手机的时候他看到了，这个人真是够贼。
　　“问你最近怎么样呢！不回？”栾念睥睨她一眼，大有我倒是要看看你准备搞什么鬼的意思。
　　“回。”尚之桃拿出手机回给辛照洲：“是啊，我结婚啦，过得还挺好哦。”
　　“就这样？”栾念显然不满意，这个过的还挺好显然不够具体，他希望尚之桃回的具体点。比如我老公特别英俊、对我特别好之类的话，这样“挺好”才能有具体形状。
　　说到老公，尚之桃从来不叫他“老公”。
　　好像“老公”这个词有多怪异。
　　“那我再细致点？看起来像炫耀，不必了吧。”尚之桃又将手机丢到一边：“我饿了。”
　　“那你去做饭。”
　　“我做的不好吃。”
　　“我比你大六岁，大概率我会比你早死。你不会做饭，我死了你饿着吗？”
　　“……”
　　尚之桃切了一声裹上衣服跳下床，简单洗漱后进了厨房。家里什么都有，但她到了厨房看到那些东西一时之间不知从何下手。栾念站在那看她胡乱折腾，终于颓败的住手，回头可怜巴巴的看着他，在求助了。
　　“叫老公。”
　　“？”
　　“叫老公，给你做饭。”
　　栾念想听听尚之桃叫他老公什么感觉，别结了一次婚连老公都没听人叫过，这婚不是白结了吗？娶了个兄弟吗？
　　尚之桃憋了半天，别别扭扭叫了一句：“老公。”
　　栾念嘴角耷拉下去，感觉真怪异：“以后别叫了。”
　　将尚之桃推到厨房外。尚之桃最近喜欢啃骨头，跟狗一样，栾念昨天半夜高压锅压了一锅羊蝎子，这会儿开了火，让尚之桃洗菜。然后穿上雨衣，也给卢克穿上，带它下楼尿尿。卢克年纪大了，不像从前那么爱冲撞，加上草地里滑，摔了个踉跄。栾念在雨里乐了一声，嘲笑它一句：“不中用了吧？”
　　卢克大概率是听懂了，冲栾念汪了一声。
　　“不丢人啊，谁都有老那天。”专捡卢克不爱听的说。
　　雨下的大，一人一狗都成了落汤鸡，栾念将雨衣挂在门口，拉过卢克来给它擦毛，又烘干，怕它生病。都说狗年纪大了不能生病，病一次老一点，所以全家人都把卢克当宝贝。就连梁医生偶尔见到，都要把它供起来一样，还像模像样给它检查身体。
　　栾念就嘲笑梁医生：“你学的不是兽医。”
　　“医理相通你懂不懂啊？”梁医生给卢克看完，说：“我们卢克可真棒，身体健健康康的，能活成长寿狗。”
　　折腾了好一通，羊蝎子开锅了，两个人坐在餐桌前准备开饭。尚之桃提议喝点，栾念拒绝：“我不喝。”
　　栾念戒烟戒酒了，因为梁医生偶然有一天对他说：年纪大了，如果还打算要个孩子，还是要戒烟戒酒。他烟抽的少，一天三两根，有时不抽，酒喝的多。但自从梁医生说完，他就一口酒都不喝了。
　　“我觉得可以喝点，老公。”尚之桃故意逗他，看到栾念脖子上起了鸡皮疙瘩，就笑出声：“你叫我一声老婆看看！”
　　“老婆。”
　　尚之桃仔细体会了一下，还行。
　　“喝点吧？”尚之桃想小喝那么一口，栾念拿了苏打水给她：“你也不许喝。”
　　“你从前不是说百无禁忌？”尚之桃抗议。
　　“你喝一个试试？”栾念懒得跟她辩论，直接对她立眼睛。
　　尚之桃乖乖喝一口苏打水，然后戴上一次性手套啃羊蝎子。她爱啃骨头，栾念就羊蝎子羊棒骨搞了一锅，她心里特别知足。
　　“所以辛照洲只是为了跟你叙旧？”栾念问她。这个人太小气了，都过了一个小时了，他还记得这事。
　　“不是。”
　　“？”
　　“他给我转了五千块钱，说是祝我新婚快乐。我没收。”
　　栾念看她一眼，尚之桃真是拎得清。
　　“他为什么给你转钱？”栾念又问。
　　“……因为他结婚…我….”随份子了。都过去那么多年了，现在也不会见面，只是随个份子而已。毕竟还有同学情谊在。
　　“收。”
　　“什么？”
　　“他转给你的份子钱，收了。”
　　“然后呢？”
　　“我看上一顶帽子，你买给我。”
　　“……”
　　尚之桃还是把不准栾念的脉，以为他会吃醋，结果他是不想赔钱。于是拿起手机，点了收款，对辛照洲道谢。
　　“钱转给我。”
　　栾念想试试花尚之桃前男友钱的感觉，点了收款，去下单那款帽子，两个颜色，不错。
　　动作做完了对尚之桃说：“不就是前男友吗？没必要避讳我，我也有前女友，你多少也知道一点。但我觉得我比你强点，因为我不跟我前女友联系。”
　　栾念说完对尚之桃挑眉，等她的表态。　　尚之桃才不表态呢，她准备气死栾念。就自顾自啃自己的骨头，吃的非常开心。
　　她不表态，遭殃的就是她。
　　下午她看的时候，栾念将她从椅子上捞起，一把放到冰冷的桌上。
　　她的肌肤挨着凉，身体颤抖了一下。
　　“我冷。”
　　“马上就热了。”栾念将她裹进怀里，额头抵着她的，问她：“现在感觉到我偏爱你了吗？”
　　尚之桃仰起头咬他嘴唇，代表是了。
　　“以后还有更多偏爱。”
　　“你受着就行。”
　　栾念心想，什么新照洲旧照洲，都得靠边站。这女人在我身边呢，我自己会好好疼，其余人等退散就好。
　　如果能有个孩子就更好了。
