# 第137章 番外三,梁成敏

栾明睿被梁成敏气的不轻。
　　医生？老师？工人？做梦吧你！你这辈子就安心当个体户的小老板娘吧！
　　板着脸回到家,栾明成一看他神色，就凑上前来：“哥，你换药去了？”
　　“嗯。”
　　“那你看见那那个吓人的女医生了吗？”
　　“你说谁吓人呢？不是你在医院里嚷嚷人家至于跟你急吗？”人还没娶回家呢,栾明睿就不许弟弟说了。
　　“不是,我想说的是你猜怎么着？那女医生是我同学的表姐。叫梁成敏。”
　　栾明成敲了敲自己脑袋，自言自语道：“梁成敏？前段时间有人给你介绍那个不也叫梁成敏？不也是个医生？”
　　栾明睿打断他：“有话直说。”
　　“哦，对。说是那女医生二十七了不结婚，说是的时候跟班里一个男同学好上了。后来男同学走了。”
　　梁成敏？跟别人好过？
　　就她那呆子样儿，摆明了情窦未开,跟谁好？
　　栾明睿笑梁成敏情窦未开，说的好像他开了似的。二十九岁的人了,对象没处过一个。在那个时候也算怪胎了。也就老天爷待他不薄,给他一张好脸。长得不好的三十来岁不结婚,叫光棍儿；他这样的不结婚，就成了挑剔了。
　　他心里惦记把梁成敏娶回家,她说的那些屁话他都记在心里，准备秋后跟她算账。眼前头等要事是把她人娶回来。别回头真杀出一个呆子来给他添乱。
　　第二天又赶着梁成敏快下班的时候去，问了护士,她还坐诊,于是又挂了她的号。推门进去,看到她正朝自己手上扎针灸。栾明睿从前跟医生接触不多，并不知道好多医生护士功课都是这么练出来的。在他看来梁成敏朝自己手上扎针的行为很怪异，她脑子成是学习学坏了。
　　梁成敏见他进来，把合谷穴上的针撤了,睥睨他一眼：“干嘛来了？”
　　“换药。”
　　“不用天天换,出去吧。”
　　“伤口好像烂了。”
　　“胡说道！”梁成敏对自己医术有信心,怎么可能她包扎的伤口会烂掉？站起来剪他的纱布,冰凉的指尖碰到他胳膊，他戏谑：“医生你不带手套？操作不规范吧？”
　　….
　　梁成敏准备赶人了，他一把握住她手腕：“不识逗。”
　　梁成敏甩开他手：“你这人怎么动手动脚的？我跟你熟吗你就逗我？”
　　“一来二去不就熟了？”
　　“谁跟你一来二去？”
　　“眉来眼去？”
　　栾明睿这种人讲这种话，根本不像在调/情，分明就是在抬杠。梁成敏要烦死他了，打开纱布：“烂了吗？哪儿烂了？”
　　“没烂就好，帮我包上吧。”
　　梁成敏点点头：“嗯，我给你包。”缠纱布的时候她手劲故意大了点，栾明睿喉咙里哼了一声，低下头，疼的脖子红了一截。
　　梁成敏突然笑了。
　　她笑起来特别好看。
　　本来就是一个清秀的姑娘，只是平时因为多了看着有那么一点古板。这么一笑，就像南方的青石板缝儿里孤零零开一朵小花，就是那么的惹人怜惜。
　　栾明睿看她笑，目光幽幽的，带着要将人吞了的劲头。
　　梁成敏撞上他目光，红着脸训他：“你看什么看啊！”
　　她红脸，他得趣，就逗她：“梁医生要不要跟我结婚？结了婚随便你怎么跟我嚷嚷，我不会急。你这个臭脾气也没人敢娶你，不如跟我凑合凑合。”
　　“谁跟你凑合？一辈子不嫁人也不嫁你。”梁成敏讨厌栾明睿那个样儿，平时板着脸像谁欠他钱，讲话又冲，好好的话到他嘴里都带着嘲讽。就连婚姻大事他说着都像儿戏，听不出什么认真劲儿。
　　她一生气脸更红了。
　　栾明睿看了她一眼，笑了。他难得笑，笑的时候有那么一点温柔。
　　栾明睿每天都来，胳膊好了以后他就在医院门口等她。梁成敏躲着他，每天下班前让小护士帮忙看看，那个瘟神在那吗？小护士一看，在呢。梁成敏就从后门走。
　　这天刚出后门就看到栾明睿站在那：“你躲我？”
　　“你老来医院影响不好。”梁成敏说。
　　“什么影响？我未婚你未嫁我等你怎么了。”
　　“你情我不愿，对我影响不好。”梁成敏跟他犟嘴，眼睛都不敢看他。
　　“行。”栾明睿丢下这一句，走了。梁成敏总这么躲着他，他们俩像猫抓老鼠，一个追一个跑，日子久了就觉得没意思。搞对象这种事，栾明睿突然悟了，有来有往才有意思。
　　下一天就真的不来了。
　　梁成敏说不清对栾明睿什么感觉，看见他就想跟他掐架，他没来，她心里又会空落落的。
　　医院里的同事好几天没见到栾明睿，就跟梁成敏打趣：“公子哥儿不来了？”
　　梁成敏红了脸：“来不来跟我有什么关系？”
　　骑着那辆大二车，左一下右一下回了家。吃晚饭的时候梁母问她：“今儿傍晚时候邻家的王奶奶说前几天在医院门口见你跟一个年轻男子讲话，是谁呀？”
　　“病人。”
　　“哪个病人？”
　　“…不记得。”梁成敏知道王奶奶讲的是哪一个，还不是那位公子哥儿？但她就是不想跟妈妈讲，怕她上纲上线。
　　“哦哦。”
　　后来她又去相了几次亲。
　　对她来说，相亲就像政治任务，她必须去，不去就是思想觉悟不够。她怕梁母唠叨，就真的去。
　　这一天相亲是在国营饭店，她刚一进门就看到栾明睿坐在靠窗边的位置，手里摆弄一颗不知哪里来的扣子。她琢磨着躲开他避免尴尬，结果撞到栾明睿的眼，他淡淡看她一眼，装不认识她。
　　再过一会儿，他的相亲对象来了，她听到他问那姑娘：“喜欢吃什么？随便点。”姑娘很好看，细细的眉眼，讲话轻声细语，典型的南方姑娘。
　　“我都行。”姑娘没像梁成敏那样敞开点，只点了一个炒青菜。反倒是栾明睿，点了虾和蟹。他说：“不用省钱，钱留着也带不走。”
　　栾明睿跟姑娘讲话，耳朵听着梁成敏那桌。听到她对面的小伙子说他是老师的时候，偏头看了一眼。小伙子穿的很干净，人长的也清秀。
　　“老师很好。”梁成敏认真点头：“教育人，桃李满天下，非常高尚。”
　　“医生救死扶伤，也高尚。”
　　互相吹捧上了。
　　“所以你平时经常去外地吗？”姑娘问栾明睿。
　　“对。”
　　“介绍人说你想找一个能顾家里的。”姑娘脸有点红，她从前就知道栾明睿，远远看过他几次。小城里多少姑娘喜欢他呢：“你觉得我还行吗？”
　　姑娘很直接，要栾明睿一个答案：“我回去会告诉介绍人。”栾明睿指了指桌上的虾和蟹：“多吃一点，别拘谨。”
　　“你经常相亲吗？”姑娘突然问他：“你是不是相了很多亲，有心上人了？”
　　“相过一次，医生。自视甚高，我不喜欢。”
　　梁成敏听到这句自视甚高我不喜欢，不知道为什么心里好像被什么敲打了一样。
　　姑娘不好意思，总觉得在栾明睿面前剥虾不自在，不像梁成敏，翘着兰花指，对那虾蟹势在必得的样子。
　　梁成敏跟男老师吃过饭，要走的时候，男老师问她：“改天要一起去图馆吗？”
　　“好啊。”
　　栾明睿听到这句“好啊”终于抬起头认真看了她一眼。他天天去医院门口等她，她见他像见着鬼一样。别人约她去图馆，她说好啊。
　　挺好。
　　栾明睿起身送姑娘回家。姑娘家跟梁成敏一个方向，这条路上去一直走，她家就在路边。他心情不好，一直到姑娘家门口都没怎么讲话，转头向回走，看到梁成敏和那男老师一起走路。梁成敏根本不像在他面前那样，撒腿就跑，这下好，沉稳了。
　　栾明睿心想，你爱嫁谁嫁谁？管我什么事？面无表情从她面前过去。
　　梁成敏突然来气，来也是你，装不认识也是你。就大声叫住他：“栾明睿！”
　　栾明睿回头看着她：“怎么了梁医生？”
　　“你没看见我？”
　　“没看见。我视力不好，我是四眼。”
　　说完就走，把梁成敏一句话噎在那，气的脸通红。眼里不知怎么就蓄上了泪水，撒腿跑了。男老师在后面愣了一愣，追也不是，走也不是。
　　再过几天，她好不容易能休息一天，吃午饭的时候梁母又给她安排：“今天下午这个你努把子力。之前跟你相亲的那个栾明睿你记得吧？介绍人说人家成了。”
　　“谁成了？”
　　“栾明睿啊。说是双方家长准备见面了。”
　　梁成敏一口饭堵在嗓子眼，无论如何咽不下去。这时才发现，那个问她要不要嫁给他的人当时就是逗着她玩。
　　她吃过饭回屋里看，躺在床上，整个人就有点蔫，也不知怎么了，或许是吃饭时梁母问那一嘴，让她想起栾明睿。于是干什么都没劲头，翻两页就放在手边。瞅着窗前瓶子里插的那支桂花发呆。再过一会儿，在床上一歪，睡着了，这一睡睡到了天黑透。梁母看她睡的香，知道她平日辛苦，就不忍叫她。
　　当一声，一颗小石子砸在她窗上，她躺那没动，以为是小孩子调皮。再过一会儿，又一颗，力道跟刚刚差不多。小孩子手可没这么稳。她坐起来推开窗，看到站在青石板路上的栾明睿，月光笼着他，将他整个人洗的干干净净的。
　　她腾的红了脸，速速关了窗，独自坐在窗前喘气，也不知怎么心跳的特别快。
　　再一声，栾明睿又丢了一颗石子。
　　她推开窗，小声问他：“你砸我窗干什么？”像小蚊子，还立眼睛。
　　“你出来。”栾明睿也小声叫她。
　　“到睡觉时候了！”
　　“出来。”
　　“我不出去！”
　　又砰一声关上窗。
　　栾明睿又丢了一颗石子，把梁成敏丢烦了，顺手捡起石子开了窗用力丢了出去，听到一声闷哼，推开窗。看到栾明睿捂着眼镜。
　　“砸到你了？”她问。
　　栾明睿不讲话，梁成敏这下看出来了，他生气了。
　　“你等我。”梁成敏胡乱披一件秋衫蹑手蹑脚走出去，小心翼翼关上家门，走到栾明睿面前。
　　“我看看你眼睛。”
　　栾明睿不讲话，把眼镜丢到她手中，转身就走。梁成敏看到那镜片缺了一块儿，就在后面追着他，跟他拐进一条巷子。巷子悠长，也没有人，偶尔过一只野猫，爪子踏在石板上哒哒哒的。梁成敏腿又紧着挪腾几步，上前拉他手腕：“你站住！我看你眼睛！”
　　栾明睿终于停下脚步站在那。
　　他个子高，她看不到，索性踮起脚，还是看不到，又急了：“你低头行不行？”
　　栾明睿低下头，呼吸落在她额头，看着梁成敏仰头看他，难得的乖巧。他眼皮上有一道轻微血痕，应该是被眼睛的碎片划到了。
　　“疼吗？”
　　“不疼。”
　　“哦。”
　　她站离他，问他：“你干什么来？”
　　“给你送喜糖。”栾明睿变戏法似的从怀里拿出一颗酒心巧克力，这东西当时少见，梁成敏吃过一两次，她很喜欢。但今天她不想吃。
　　“你给我送什么喜糖？你跟我炫耀呢？你是不是想说你不嫁给我有的是人愿意嫁给我！”
　　“你是不是逮着一个姑娘就问人家要不要嫁给你？还是看你心情？”
　　“你结婚了不起啊要在我面前耀武扬威！”
　　“谁要吃你的破喜糖！”梁成敏说着说着急了，急了眼睛就红了，她也说不清为什么，觉得有点委屈，还有那么一点遗憾。
　　栾明睿看到梁成敏眼里滚下一滴泪，终于不忍心逗她了：“我表妹的喜糖。”
　　…
　　要是地上有个洞，梁成敏就钻进去了。她抿着嘴，泪眼汪汪的。
　　“吃么？”栾明睿又问她。
　　“吃。”梁成敏抹掉眼泪摊开手掌，栾明睿将巧克力放在她掌心。她撕了锡箔纸，将它放到口中，舍不得咬碎，就那么含着。
　　“好吃么巧克力？”他问她，声音有点哑。
　　“好吃啊。”
　　“我尝尝。”
　　他突然低下头亲她嘴唇，舌尖在她唇角舔了舔。梁成敏头脑轰的一声，愣在那。
　　栾明睿的唇再来的时候，她像个傻子。
　　栾明睿不傻，他不会，但他一心想尝巧克力，手扣着她的头，舌就探了进去，这一探不得了，姑娘香甜的唇舌和淡淡的酒气让他近三十年的铁树霎时开了花。舌尖勾着她的，将她舌上的巧克力着着实实吸过来，连带着她的舌，手捧着梁成敏的脸有那么一点无师自通的意思，又觉得两个人离的太远，猛然把她揽到怀里。
　　梁成敏撞到他的身体，他杵着的东西吓到了她，在他怀里挣扎：“放开我！”
　　“不放！”
　　“我喊人了啊！”
　　“你喊！”
　　栾明睿将她困在他与墙之间，两个人在博弈，哧哧的喘气：“不喊是吗？”栾明睿问她，看她的眼睛可怜巴巴的，又去亲她。这次比刚刚还要急，牙齿撞到牙齿，他也不管，偏过头去终于找到合适位置。
　　梁成敏站不住，他捞起她，身体缠上去，做她的把手和靠山。
　　最近天天惦记她，却放不下面子。今天别人结婚，他突然羡慕，尊严面子能有把梁成敏娶回家重要吗？
　　当然没有！
　　娶回家再慢慢收拾她不好吗？现在跟她较什么劲！
　　好不容易分开了，栾明睿心里满当当的，又问她：“梁成敏，要不要嫁给我？”
