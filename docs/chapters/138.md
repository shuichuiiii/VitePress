# 第138章 番外四:梁成敏

梁成敏点点头又摇摇头。她头晕脑胀的,酒心巧克力早没影儿了，口腔里只剩一点甜腻的酒味。
　　栾明睿鼻尖擦着她的，他不会讲什么甜言蜜语,讲话就是这么直来直去：“问你呢,梁成敏，你愿不愿意？”
　　“你如果愿意明天我就让我父母去你家里。我不是老师、医生、工人，但我保证你跟我以后我不让你挨饿。让你每天都吃你爱吃的虾和蟹。”栾明睿开始诱哄她。
　　梁成敏终于反应过来，伸手推他，推不动,两个人就这么在黑夜里僵持，她贴在墙上,他贴着她,鼻尖挨着鼻尖,呼吸接着呼吸。
　　“谁要你养！我…”她开口讲话，栾明睿听进去也没听进去,他第一次亲人，发现那感觉好极了。梁成敏讲话的时候她香甜的味道让栾明睿失神，索性去堵她的唇,他找到了一点门道,用力吮她,梁成敏头脑里又轰一声。
　　“你什么？”栾明睿贴着她唇问她。
　　“我是医生，我能养得起自…”栾明睿咬她嘴唇，就是不让她讲一句完整话，来来回回三五次,两个人都有点气喘吁吁,梁成敏的话终于讲完了。她的大意是我用不着你养,我好歹是医生,我就算不能每天吃虾蟹，发了工资我也可以打一次牙祭。
　　“我听明白了。你的意思是不愿意是吧？”栾明睿瞪她：“不愿意你这是干嘛呢？大半夜跟一个男人在小巷子里又亲又抱，你耍流氓呢？”他倒打一耙，故意气她。
　　“是我耍流氓吗？”梁成敏要被他气死了，伸手拧他腰，真没省着劲儿，栾明睿疼的哼了一声，握住她手腕，嘴里还不饶人：“你摸哪儿呢梁成敏？你怎么不再往下点儿？”
　　梁成敏真没想到栾明睿是这样的人。医院的小护士说他是清高的公子哥儿，对人没有笑模样，说他家底子厚，家里的孩子也算饱诗。护士说的跟眼前的是一个人吗？他怎么这么无耻！
　　栾明睿见她急了见好就收，终于放开她，向后退一步：“不嫁给我，行。要不要跟我自由恋爱？”
　　“不要。”
　　“不要你脸红什么？”
　　“脸长在我身上，你管得着吗？”
　　梁成敏推他一把，转身跑了。进了家门跑回自己的小小房间，将窗开了一个小缝儿，看到栾明睿还站在那，像个大傻子一样。
　　梁成敏也不知道心里惦记一个人是这样的。
　　闭眼睁眼都是栾明睿那张脸，还有他抱着她哧哧的喘气。第二天睁眼的时候眼睛通红，像小兔子。吃了早饭出门，看到栾明睿站在她家门口。
　　脸又红了：“你怎么来了？”
　　“送你上班。”
　　“不用你送我上班。”
　　“就送。”
　　栾明睿跨上自行车，指指后面：“上来。”
　　“我自己有自行车。”
　　“你腿太短，骑二车太滑稽。”
　　“……”
　　梁母听到声音出来，看到僵持的两个人。梁母是认识栾明睿的，这小伙子在小城里名气大着呢。
　　“你们干什么呢？”
　　“阿姨好，我来送她上班。”栾明睿大大方方的。
　　“你不是要结婚了？”梁母问。
　　“谣言。结也是跟梁成敏结。过两天我父母就来。请阿姨放心，”
　　“谁要跟你结！”梁成敏急了，在他身上拍了一下。在梁母看来，这两人是在打情骂俏呢。就说：“要晚了啊，抓紧。”梁母对栾明睿印象好，这小伙子看着多端正，跟自己女儿配着呢！
　　梁成敏跨上自己的自行车，左一下右一下骑走了。栾明睿在她身后跟着，看风把她的衣裳吹的鼓起来，青石板路不平坦，自行车看起来一跳一跳。
　　栾明睿看着这样的梁成敏就觉得这姑娘真不错。
　　这姑娘除了脾气臭点，真是什么都好。
　　跟着她到了医院，她下了自行车，他坐在车上、一脚支在地上，一手把着车把，另一手腾出来握住她手腕：“梁成敏，我昨天晚上说的是认真的。”
　　“你说什么了？你昨天晚上就耍流氓了！”梁成敏小声训他：“再耍流氓我就举报你！”
　　“行。我晚上再来接你去吃饭。”
　　“我不去！”
　　梁成敏说她不去，这一天却惦记像回事一样。她觉得栾明睿挺讨厌的，她从前一心钻研医术，这还是头一次为一个男人分了心。
　　到了下班的时候，推着车出了医院，栾明睿果然等在那里。手握住梁成敏自行车把将车接过来，自行车在地上漂移了一下，就到了他腿下，指指后座：“上来。”
　　“不上。”
　　“不上你走路去吃饭？”
　　“那是我的车！”
　　“你知道你骑这车多滑稽吗？”栾明睿学她在车座上左一下右一下，路过的人笑了。
　　“栾明睿！”梁成敏急了：“你有病吧？！”
　　“对，我有病。等结婚了你慢慢给我治。”
　　栾明睿这个人向来稳准狠，他认准的事必须得成，他认准的姑娘必须娶回家。哪怕他看着一反常态，像个臭无赖呢，无所谓，他自己愿意。先把消息放出去，人占上，就是这么卑鄙。
　　他这句话可是挺吓人，周围经过的下班的人都停下脚步看着他们：梁医生要结婚了？都没听说梁医生有对象，这怎么就要结婚了？
　　梁成敏跟他急了：“你胡说道！光天化日朗朗乾坤，你…”
　　“我什么？你走不走？不走我跟大家说一下酒心巧克力的事？”
　　栾明睿话音刚落梁成敏就跳上后座，手捏着他衣服：“快走！”
　　生怕栾明睿那张破嘴什么都说。
　　她不知道她怎么就招惹了这么一个瘟神，最可怕的是她竟然惦记起了这个臭无赖。
　　栾明睿突然捏了车闸，梁成敏坐不稳，脸撞到他后背上，下意识搂住他的腰。又听栾明睿说：“抱紧了啊！”
　　他带着她在小城里穿梭，栾明睿身上的味道干净又好闻，梁成敏一颗心飘飘忽忽的。
　　到国营饭店门前，栾明睿蹲下去给自行车上多，梁成敏看到他干干净净的手指、理的整整齐齐的头发，突然就觉得跟他结婚能差到哪去？至少她昨天晚上惦记他一整夜呢。
　　等栾明睿站起身的时候，梁成敏对他说：“栾明睿，这饭我不能白吃。”
　　“你请我也行。你是不是发工资了？”谁请都行，坐下吃就行。
　　“我的意思是我同意跟你自由恋爱，也不怕嫁给你。”她通红着一张脸，像十七岁女孩一样害羞又坚定。
　　栾明睿看着她，突然笑了。她上班的时候多老成，一会儿严肃一会儿难过，满脑子都是她的病人。下了班，就变成一个没长大的小姑娘，特别单纯，特别干净。
　　手指捏了捏她的脸，路过的人看他们，他们也不怕。怕什么呢？
　　栾明睿行动特别快。当天回家就宣布他要结婚的消息，他主意正，但从来不胡来。他说要结婚就是真的要结婚了，于是在他请父母准备好东西去梁成敏家的时候，父母二话不说立马同意。
　　他们知道那个梁医生，小城里拔头份的姑娘，人品好、工作好、父母也靠谱，万万没想到在那次相亲双方彼此回绝后，栾明睿不声不响的快速的就搞定了人家姑娘。
　　栾明成在一边啧啧出声：“我说你怎么不让我说她脾气臭！”
　　“她嫌你是四眼！现在不嫌了？”
　　“你们俩的脾气一起过日子还不得天天干架！”
　　“关你屁事。”栾明睿瞪他一眼。
　　栾明睿跟梁成敏结婚那天，小城里特别特别热闹。都不觉得这俩人是年龄到了凑合结婚，为什么呢？瞧他们往那一站，把整个小城都点亮了。多般配啊！
　　是得他俩结婚。
　　不然还能跟谁呢？
　　栾明睿偷偷勾她手指，指尖在她手心划了一下。梁成敏在人前红脸，却一动不敢动。任由栾明睿握住她的手，隐秘的甜蜜。
　　梁成敏偷偷问过自己，是不是爱栾明睿，不爱为什么要结婚？她在结婚头一天晚上把两个人的过往想了一个遍，她觉得她是进了栾明睿故意撒的网了。他就是个坏人。可她又不在乎，她这辈子还是第一次惦记一个男人，这种感觉很好。
　　小城结婚热闹，喜宴摆长街的热闹。两个新人胸前各别一朵红花，梁成敏头上盘着小辫子，笑起来天都晴了，特别好看。
　　栾明睿看梁成敏看不够。
　　在乡亲邻里、亲朋好友面前也忘了掩饰，也不管这会不会伤害其他姑娘的心，总之就是喜欢看她。
　　敬酒的时候栾明睿有意少喝，后来干脆拉栾明成帮他挡酒。栾明成不解：“你结婚不让我替你喝酒？”
　　“懂什么！”
　　栾明睿惦记晚上呢，喝多了还过什么晚上！
　　医院的同事跟梁成敏喝酒，栾明睿也推栾明成上去：“我们家派一个陪各位喝，梁成敏酒量不好，喝多了影响她上班。”
　　“她明天不用上班。”同事打趣。
　　然后大家哄堂大笑，都明白这对小夫妻在躲什么了。多数人都从这一天过来的，于是就不为难他们。酒换成了白水，碰杯的时候一样响，只要开开心心比什么都强。
　　到晚上闹洞房，象征性闹了闹就散了。
　　突然屋里只剩他们两个人。
　　梁成敏坐在床头，栾明睿坐在床尾，连呼吸都是小心翼翼。
　　外面窗子响了一下，有人小声说：“怎么没动静？”
　　栾明睿讨厌被听墙角，推开窗看到几个毛头小子撒腿跑了。
　　又关上窗坐回床头。
　　过一会儿问梁成敏：“你是不是特别了解人体？”
　　“是。”
　　“那你研究研究我吧。”
