# 第151章 她他:他们的爱

2010年的夏天的一个夜晚，栾念在醉酒后想起一个人。
　　他醉酒后通常不会给任何人打电话，他很少有喜欢的人，也不需要谁在酒后照顾他，所以他从未在醉酒后想起过谁。他想起“笨蛋”尚之桃。很奇怪。在他心中，人都伪善、都不值得深交，但他却信任她。
　　在他还清醒的时候，他打给了她，电话接通的时候，他听到她的惊慌，好像自己犯了什么错误。
　　他说要她帮忙送资料，并报了地址给她。他的确是醉了，却并没醉透。他知道她拧了湿帕子为他擦脸，察觉到她费力地想将他的身体挪腾正，偏偏他又不愿配合，在腿部用了些力气，听到她呼哧带喘，他麻木的内心依稀是见到一点光。
　　真坏。他在心里唾弃自己。可我挺喜欢逗她。她有点可爱。
　　她走的时候，将他家里的热闹也带走了，他彻底醉了过去。
　　后来的尚之桃跟栾念讨论过这件事，是在2015年，他们恋爱的时候。尚之桃对那个夜晚印象深刻，又觉得发生的事很突兀。最终得出结论：是栾念故意勾/引她。栾念自然不会承认，只是懒懒地靠在沙发里，看着尚之桃，似笑非笑地说：“你只要记住，这辈子除了我，再也不要单独去醉酒的男人家里。没人像我这么好。男人都是畜生。”
　　“你怎么好了？你是老狐狸，撒网等我进。可能别人就是纯畜生了…”尚之桃已经历练了几年，开始跟栾念有来有往，有时贬损起栾念来也是不留情面的。栾念哼了声，吓唬她：“总之你给我记住！”
　　尚之桃从栾念这里得不到答案，但她开始笃定他那时就对他有明晃晃的心思。
　　尚之桃也问过他：“那你是什么时候想跟我发生关系的呢？不许说谎哦，说谎变小狗。哦不，变猎狗。”在她心中栾念是一头猎犬，整天龇牙咧嘴，很是凶恶。
　　栾念也不肯回答她，半眯着眼睛看着她套着一件宽大的T恤光着双腿在他面前走来走去。这是他们难得的能在一起的悠闲的周末，她好像很开心，路过卢克的时候拍打它的头：你该减肥啦！卢克！卢克察觉到她的开心，汪了一声，跟着她在屋子里走来走去。
　　栾念的内心被幸福填满了。
　　那种满当当的幸福和安稳，是他从未体会过的。这种感觉令他整个人轻飘飘的，忍不住朝尚之桃伸出手：“你来。”
　　“干嘛？”尚之桃朝嘴巴里塞了两颗草莓，两边腮帮子都鼓起来，故意对着栾念。
　　“大傻子！”栾念笑了，起身将她拖拽到他的怀里：“别动！”他说。
　　“可是我想多走走，这样我待会儿才能多吃一点。”她早上被栾念的新的煎蛋手法惊艳了，生生吃了三个煎蛋、两片面包、还有一大杯桂花牛奶，导致她吃多了，一直在房间里踱步。
　　“没事，我们可以晚点吃午饭。”栾念答应今天给她做海鲜大餐，因为她在西北一直吃牛羊肉，很想这一口。她说要去吃海鲜自助，栾念差点骂她：“那破玩意儿有什么好吃的？用料不好，烹饪也是凑合。”
　　“那…”
　　“我在家里给你做。反正我不吃那破东西，你喂卢克你看卢克吃不吃？”
　　卢克“汪”了一声：不吃！
　　“可是我想早点吃…下午我想去找卢米和孙雨。”尚之桃有些为难，她很少回北京，很想念自己的朋友。
　　栾念心中一沉，刚刚那些满当当的幸福好像消散了一些，他不再说话。
　　尚之桃察觉到他的沉默，转过身看他，用下巴蹭着他脸颊，说：“我决定…把吃饭时间改到明天晚上！”
　　栾念忍不住扬了下嘴角：“算你有良心吧。”
　　尚之桃捧着他的脸胡乱亲，草莓的香气绕着栾念的鼻子走。她吃饱了，却还能吃点草莓，真是奇怪的女人。想起她刚刚忽视他，又生起气，在她屁股上狠狠拍了两下。
　　“栾念！”尚之桃低声喊：“你欺负我！”
　　“就欺负你！”
　　栾念翻个身将她压在身下，手伸进了她的阔T恤中。他下周要去日本出差，不知来不来得及飞去西北，想到倘若去不了，那么他将半个月见不到她。而他又不知她是否会像他一样，对这半个月的分别感到沮丧，因此他有些生气。
　　“栾念…”尚之桃握着他手腕：“你不是说今天戒色吗？”
　　“你就当我放屁。”
　　尚之桃咯咯笑出来：“你连自己都骂！”
　　栾念要把下一周的提前预支出来，他像一个性/瘾患者，不停盘剥着尚之桃，要将她整个人都榨得干干净净。期间尚之桃好像在求饶，他停下问她是不是不喜欢，但看到她湿漉漉的、迷茫的眼睛，确定她喜欢死了。
　　他早已接受尚之桃去西北的事，也已习惯在周五晚上飞去西北。他甚至觉得她在西北也挺好，因为她去了西北，再不用周六上午从他家里急匆匆走了。他们窝在她西北的小家里，不停做/爱、聊天、看电影，积攒了一个星期的话，都会在那两天说尽。
　　尚之桃快要窒息了似的，滚烫的热意爬满她身体的每一个角落，她的大脑一片空白。这时她会抱着栾念不停地说：“爱你，爱你。”她知道这个时候，她的身体和心灵都在爱着他，都离不开他。
　　“爱你。”栾念将她抱得更紧，纠缠着她的舌头，问她想不想再来一次。尚之桃点头：“我要，我还要。”
　　浓烈的情感弥散开来，化也化不尽，停也停不下。这个时候他们都无比确定他们在相爱着。
　　后来他们睡了片刻，栾念的手机一直在闪，都是他的工作消息。尚之桃让他回，他却把手机丢到一边，骂了一句傻逼。
　　尚之桃问他怎么了？
　　他说：都是傻逼。
　　栾念身处这个行业，玩着资本的游戏，深知一切东西都是资本的筹码，他对此早已深恶痛绝。在他心里，那一切都是傻逼。
　　他跟尚之桃在一起的时候并不太看手机。于他心中，这一周一次的相聚已属不易，若他再拿着手机没完没了地看，那么在一起还有什么意义呢？他自己不看，也不许尚之桃看。尚之桃说：我有工作要处理啊。
　　他说：我就是你的工作。
　　…
　　他做饭，也会要求尚之桃站在他旁边。尚之桃一边控诉他，一边在他的配菜里挑拣些能吃的朝嘴里送。栾念有时打她手，她哎呀呀地躲开。过一会儿又会去偷东西吃。
　　栾念知道她不会亏待自己。西北那么艰苦，她起初吃不好睡不好，但很快就适应过来。她变着花样哄自己开心，哪里有好吃的，会央求当地同事带她去吃；哪里有好玩的，她得空也会去看一看。栾念有时会问她想不想他，她说想啊，他转头就会斥责她敷衍。
　　他有时觉得尚之桃离他很远。他原本以为相恋的人会更近，可是尚之桃看起来那么飘忽。他会因此患得患失默默生气。

　　“小心眼，记仇鬼。”尚之桃嘟囔一句，怕栾念听清楚，又呵呵笑两声。
