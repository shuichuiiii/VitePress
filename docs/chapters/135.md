# 第135章 番外一：梁成敏

梁成敏二十七的时候还不嫁人, 这在70年代的中国显得十分另类。
　　梁成敏妈妈看到女儿就唠叨：“嫁不嫁么，你给个痛快话。多少人给你介绍男朋友，你看都不看一眼。家里倒是也能养得起你, 只是邻里会讲闲话的呀！”
　　“讲就讲喽～”梁成敏讲话慢条斯理：“嘴长在别人身上, 咱们管不了的呀！”
　　她生在江苏, 在上海, 又去安徽做实习医生, 一圈跑下来专业知识长进了, 口音也杂了。
　　梁成敏妈妈看她就有那么一点上火：“你不急奶奶还急呢。”
　　“明天不管那个人什么样我都嫁！”梁成敏丢下一句就跑了。
　　第二天从医院出来，骑车到图馆, 在周围磨蹭一会儿。她28岁, 却还是小孩心性，对什么事都不甚关心，她只关心人体和病理, 一心想做女华佗。
　　图馆门口站着的那个男人显得有点突兀, 白衬衫黑裤子，身姿笔挺，眉头皱着，看起来不是好相处的人。介绍人说这个人长相英俊, 不知多少姑娘惦记。梁成敏看不出英俊不英俊, 她关心别人健康不健康。这位看着挺健康。
　　她跑过去，两条粗辫子垂在胸前, 手中抱着一本，像个呆子。跑到男人面前的时候微微喘着：“栾明睿吗？我是梁成敏。”
　　栾明睿脾气不好, 看了眼手表：“你迟到了，分钟。”
　　梁成敏不能说我是在周围打量你呢，只是尴尬的笑笑。
　　“我医院有事出来晚了.”
　　“没事。”
　　“我们要走走吗？”
　　“嗯。”
　　栾明睿随便应了一声, 两个人在马路上走。那时马路边人很少，空气中有海水的味道。每天早上会有渔船回来，带着一船的海货。梁成敏从小身体不好，再大一点，父母听说吃虾蟹强身健体，就想法设法搞来，每天做虾泥剜蟹肉给她吃，日子久了，她看起来比一般的南方姑娘骨架大那么一点，整个人水灵灵的。她这样的身段，走在栾明睿身边还是显娇小。他个子高，身板平直，带着一副眼镜，梁成敏偷瞄一眼，还行，度数不大。
　　两个人说了自己的情况，都对相亲没什么心思，随便说两句就算了。
　　梁成敏刚进家门，介绍人就进了门，拉着梁母站在窗外讲话，起初梁母还挺兴奋，两句话后就有一点没精打采：“哦，觉得不合适是吧？没事没事，要讲缘分的。不合适不能硬凑，人家确实家境比咱们好那么一点。瘦死的骆驼比马大嘛。”
　　梁成敏咳了一声：“妈，我这开着窗呢，说什么我都听的清清楚楚。这有什么可难受的，我也没看上他啊！”
　　介绍人听到这句，从窗户探头进来：“你没看上人家？”
　　“没有。他是四眼。”
　　“你不也是四眼吗？”介绍人指出事实。
　　“我不是，我不到一百度，不戴眼镜也可以。他度数大。”
　　介绍人听完这句：“啧啧，这年轻人呀，一个赛一个挑剔。这么挑下去要在家里待到老啦。”已然忘了是别人先挑的。
　　梁成敏不把这档子事放在心上，不嫁就不嫁嘛，嫁人有什么好。医院里的医生护士结婚的大有人在，常有人哭鼻子上班呢！
　　她平常没心没肺，像长不大的姑娘，一坐诊就极其严肃，白大褂一穿，头发一盘，医生帽一戴，要多严肃有多严肃。
　　这天坐诊，来了个声称自己骨折的。
　　进门就哇哇叫，无论梁成敏说什么他都不听。梁成敏生气了，板着脸吓唬他：“再嚷嚷就把你嘴缝住！”她年轻医生，吓唬人也就这样了。这句落在被父母通知来照顾弟弟的栾明睿耳朵里，就对这医生起了一些偏见。
　　梁成敏认认真真给病人看，那条腿肿成了树干粗，却真的没骨折。
　　“你别再叫了，你听我说，你没骨折。”
　　“没骨折怎么这么疼？换个有经验的来！”
　　“我就是有经验的！”
　　“你一看就是半吊子！”
　　……梁成敏被他气的脸通红，问：“家属呢？”抬起头就看到板着脸的栾明睿。
　　梁成敏觉得这人有点眼熟，想了半天想起是嫌自己家境不好那个公子哥儿。但她没提那茬儿，装作不认识：“你是家属吗？”
　　“嗯。我弟弟。”
　　“你弟弟没骨折，让他别叫了。我给开药，去旁边理疗。”
　　“能换医生再看看吗？”栾明睿问她，摆明了不信任她。她才28岁，能有什么经验？
　　“能。出门，重新挂号。”梁成敏没给他好脸色，换人就换人。头都没抬，脾气可倔了。
　　栾明睿带栾明成重新挂号，是个老医生，老医生也是梁成敏那一套，对他们说：“没骨折，开药理疗吧。”
　　“那腿怎么这么肿？”
　　“伤筋了。骨折没骨折不一样的年轻人。你们可不兴胡思乱想的。”
　　栾明睿突然觉得刚刚冤枉了那姑娘，想了半天想不起她名字，就去门诊问。再回去的时候梁成敏已经下班了，换了一件碎花衬衫，正往医院门口走。
　　看见栾明睿心里切了声，目不斜视过去。
　　栾明睿也不知她是不是记得自己，那就当作不记得好了，拦住她自行车：“医生。”
　　“还知道我是医生啊？我给你弟弟看病的时候你怎么不信我是医生呢？还换人，换了，腿折了吗？”
　　梁成敏嘴像机关枪一样突突栾明睿：“还有啊，你弟弟多大人了？在医院里嚷嚷什么？丢人不丢人？”
　　栾明睿本来想道歉，见她得理不饶人，就往旁边一站，说了句能气死梁成敏的话：“换人看一下放心。怕你误诊。”
　　又高傲又气人。
　　梁成敏一口气堵在心口，瞪他一眼，走了。
　　到了家这口气还没消，就对梁母说：“以后再有人介绍对象，戴眼镜的一律不行。”
　　“为什么不行？”
　　“看着就阴险！”
　　第二天早早上班，在医院过道里看到栾明睿带栾明成来理疗，目不斜视过去。栾明成记得她，就跟她打招呼：“医生好啊！”不是昨天哭嚎那个熊样子了。
　　梁成敏停下看着他：“你谁啊？”
　　转身走了。
　　“这医生真吓人。”栾明成小声说。
　　栾明睿对他说：“你以后再受伤忍着点。在医院叫什么？不丢人吗？”
　　栾明成被哥哥训了几句，不敢讲话。他从小就怕栾明睿，总觉得这个哥哥脸上没见到过晴天。栾明睿很庆幸自己当天就回绝了介绍人，就梁成敏那脾气别说过日子了，相处几次俩人就能打起来。
　　栾明成在里面换药，栾明睿坐在外面木凳上等，听到梁成敏在隔壁诊室高一声低一声的训人：“都这样了才来？想什么呢？”
　　“我说的话你当耳旁风是吧？是不是让你忌口？你看看你这伤口！”
　　过一会儿又很温柔：“别哭了，你丈夫现在需要人照顾，你还怀着孕，你得控制情绪知道吗？”
　　年纪轻轻变脸跟翻一样。
　　栾明睿二十九岁，喜欢他的姑娘不少，他都不喜欢。久而久之就成了家里的老大难。栾家世代经商，三起三落，被抄过家也主动捐过，慢慢的家道中落。但栾家人也是奇怪，到栾明睿父亲这里，到了老，又赶上了好事，在这一年被平了反，日子就又渐渐好了起来。一家人穷过也富过，但老一辈的习惯没丢，哪怕吃个炒青菜，也得把盘子摆的干干净净漂漂亮亮。早些年的时候，两儿两女站出去，身上穿着带补丁的衣服，但那衣服洗的干干净净。透着小城人少见的体面，用邻里的话讲：矫情。
　　栾明睿就是这样。
　　他不仅矫情，脾气也差，每天板着一张脸，不知吓跑多少姑娘。头脑却好使，体制内混的风生水起，旱涝保收铁饭碗。
　　小伙子长的精神，学问好，家境好，又有钱，加上挑剔，就成了小城姑娘心里的朱砂痣。
　　梁成敏可不知道这些。
　　她从小就爱，后来学医，为了学医又离开小城几年，对小城新兴的这号人物不清楚。在她心里，栾明睿就是个眼高于顶的大傻帽。嫌她家境差，她还嫌他是四眼呢！更何况她家境哪里差，父母都在学校教，好歹也算半个香世家。
　　但梁成敏也不记仇，事情过了就过了。
　　半个多月后的一天晚上，她被梁母赶去打酱油，供销社里排了两大长队，她估摸着时间不断索性安心排队，站在那背。好巧不巧的那天栾明睿也去了供销社，就站在她旁边那队，有人叫他名字，他回头的时候看到梁成敏。好歹两个人一起相过亲，她这时一动不动，看起来有点目中无人。
　　终于轮到他们，梁成敏翻了半天兜，没带票。旁边一只干净手伸过来：“用我的吧。”抬起头看到栾明睿。
　　梁成敏怕回去被母亲骂呆子，就点点头：“行，谢谢你。我明天还你啊。”
　　打了酱油就往外走。
　　栾明睿跟在她身后问她：“你怎么还我？”
　　“？”
　　“你知道我住哪吗？知道怎么找我吗？你什么都不知道怎么还？”见梁成敏被他问愣了，又接着说：“你没打算还我吧？”
　　梁成敏急了：“你有病吧？谁差你那张票啊！没这么羞辱人的啊！我说明天还你就还你，我不知道你住哪儿我问介绍人行不行？我怎么就不打算还你了？”
　　“你记得我们相过亲是吧？”
　　“……”
　　“那你怎么跟不认识我似的？我以为你视力不好呢。”
　　他跟介绍人说觉得姑娘挺好，但不对自己脾气。介绍人跟他父母说：“没事儿，姑娘也没看上明睿，嫌明睿是四眼儿。”
　　今天算出了这口恶气。
　　见梁成敏被气的脸通红，又说了句：“明天晚上，点，还在这，你还我票。不还我去你家里要。”
　　转身走了。
　　月光如水，他嘴角那抹坏笑路人可是看的清清楚楚。
