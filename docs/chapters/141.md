# 第141章 番外七:梁成敏

小念念出生那天象征性的哭了一声,然后就闭眼睛睡觉。
　　新生儿一直睡觉，这没什么不对。可他睡觉的时候小脸儿皱在一起，本来刚出生的孩子都像猴子一样,他这样皱着脸儿就更难看。梁成敏看了他一眼突然有点发愁,偷偷对栾明睿说：“他长大会不会长的不好看？”
　　“胡说。我的儿子能不好看？”栾明睿看了眼小念念，真挺难看。心里也打鼓，不会长大了特别难看吧？照了照镜子，觉得自己没什么特别难看的地方，梁成敏更不用说了,多好看的女人呢！在他心里梁成敏最好看，别的女人都要靠边站了。
　　梁成敏躺在病床上很虚弱,一扭头就是小念念那张皱着的脸,心情一阵不好。直到出院回家了,这种心情还没消散。小念念就睡在她旁边，皱着眉头。睡觉的时候像个老头子,吃奶的时候却要了命了，吃的哼哼唧唧，力气要多大有多大。
　　梁成敏是在一个深夜发现孩子的脾气真的不好的。那天夜里,他饿了,栾明睿起来说先给他换尿布,然后再喂奶。刚做爸爸的人尿布换的不熟练，动作慢了一点，孩子就开始哭。他哭的时候脸憋的通红，差点哭背过气去,跟杀猪一样。梁成敏和栾明睿,两个大人在深夜被他哭出一身汗,□□都塞进他嘴里了,他不吃，吐出来接着哭。一直哭到他累了，才吃奶。
　　梁成敏一边喂奶一边对栾明睿说：“完了，这下我肯定了，这孩子脾气真是随了咱俩了。”
　　栾明睿不以为然：“他还没满月呢，你就能看出脾气差了？是我动作太慢，他饿坏了才哭的这么厉害。”栾明睿开始自省，甚至在心里比划这尿布怎么换能更快一点。
　　梁成敏坐月子的时候，两边老人白天过来搭把手。但栾明睿不放心，什么都要看着，月子饭必须他来做。那时都说月子要顿顿吃鸡蛋，栾明睿不以为然：“让你天天吃鸡蛋你不吐吗？不腻吗？”
　　他自己看着都不爱吃！凭什么让梁成敏天天吃？
　　于是变着花样为梁成敏做吃的。老人说坐月子要保护牙齿，不能吃硬的，就把虾捣碎成虾泥，做虾丸汤；清蒸鱼先去腥，再上蒸锅；鲫鱼汤汤汁雪白雪白的，小火慢炖出来的；鸡汤炖到鸡肉脱骨；少油少盐，但味道都好。
　　他们家饭菜香，邻里能闻出来做的是什么。坐在一起闲聊的时候就说：梁医生真是嫁对人了，看看人家坐月子吃的是什么，再看看别人吃的是什么。
　　那是什么年代啊，坐月子吃的起鸡蛋的人家都不多，他们家天天鱼肉虾不断。
　　栾明睿也清楚这样吃究竟要花多少钱，但他一点都不心疼。当初要娶她的时候就答应她嫁给他一辈子虾蟹不愁，他得做到。
　　不仅让梁成敏吃的好，让她心情也好。她整个孕期一直到生完脾气都不好，但栾明睿没跟她吵过一次。有时被她气的要背过气去，他就穿上衣服去院里站着，自己宽慰自己，什么时候气消了，什么时候再进屋。
　　他变的温柔了那么一点。
　　婚姻到底能不能改变一个人呢？或许能的。
　　栾明睿从前是多么倔强的人，无论何时都是一根硬骨头，难啃着呢。梁成敏也一样，两根硬骨头在一起过日子，起初真是磕碰在一起当当响，各自都疼。
　　慢慢的两个人都学会了让，日子就开始甜蜜了起来。
　　梁成敏在生完孩子后慢慢变的温柔。
　　不是一下子变的，是一点一点，她自己都没有发现。她还会跟栾明睿拌嘴，但并不是真的拌嘴。有时拌着嘴自己忍不住就笑了。她本来就生的一张明媚的脸，笑起来就很温柔，有时栾明睿都会看呆。偷偷对朋友们说：“我怎么觉得我换了个老婆一样？”
　　“你不喜欢？”兄弟们逗他。他们可是记得当初他被梁成敏折磨的要死的样子。
　　“不，我赚到了。”栾明睿觉得这日子也太顺心了，简直没有一点不顺心。日子一顺心，他整个人就看起来有那么一点春风得意之感。这种顺心照亮他整个零年代，也贯穿他的一生。
　　到孩子三个多月大的时候，夜里终于能睡几个小时整觉了。梁成敏窝进栾明睿怀里，脸贴着他胸膛，觉得日子好像好过了起来。
　　栾明睿借着一盏小灯看她，看到她脸上比孕期丰盈一点，他每天没白喂她，终于把她喂回了从前的样子。他心里喜欢，轻轻啄一下，又啄了一下。
　　梁成敏仰起头亲他下巴。手捧着他的脸，看个没完。
　　“怎么了？”栾明睿看到她敞开的衣领，有点心不在焉。
　　梁成敏不讲话，舌尖在他下颌上轻轻划过，落在他喉结上牙齿轻轻咬上去，喉结在她舌尖下滚动。
　　梁成敏静在那里，突然推倒他。
　　压在他身上看着他。
　　梁成敏知道从医学上来讲，刚生过孩子，身体会发生一些变化，会恢复，但需要时间。她尽管看起来满不在乎，却偷偷做过训练。深呼吸，收紧，放松。她相信科学，却第一次有点怯意。
　　栾明睿揽着她，他们在黑暗中彼此端量许久，渐渐的就酝酿了一场风暴。
　　但都觉得不自在，因为孩子就睡在旁边。
　　栾明睿轻轻吻她，舌尖碰到一起，都觉得对方很美味。
　　“不在这个房间。”梁成敏说。是跟同事聊天的时候，一个同事说起当年糗事，孩子三岁大的时候，夫妻行房事，兴致正浓的时候听到孩子叫了一声妈妈，坐起身来，看着交叠在一起的爸爸妈妈。梁成敏听出了心理阴影。
　　“好。”栾明睿带她去到另一个房间，平常没人居住，被褥很凉，梁成敏身体贴上去就凉得人蜷在了一起。栾明睿压将上来，将她碾了进去。她听到自己哼了一声，就被他堵住了嘴唇：“别吵醒念念。”
　　他说。
　　太久没有过的两个人都有点控制不住。梁成敏所有注意力都在那里，她想知道自己究竟变了多少，恢复了多少，可她感觉不到，只觉得一切情意都漫了出来。
　　栾明睿跟孩子抢饭吃，甘甜可口，他迟迟不肯松开。梁成敏羞愧难当，又喜欢这种体验。当他们舌尖又碰到一起的时候，她尝到自己的味道。
　　栾明睿特别特别温柔。
　　他做过功课的。堂兄生栾思媛后，夫妻之间恢复的第一次并不顺利，以致后面将近半年的时间，嫂子都会抵触。堂兄与他抱怨过：怎么就这么难了？他听进去了，就格外温柔。
　　哪怕他急的要死了，也还是不敢太重，总是问她：“这样好不好？这样呢？”
　　“疼不疼？”
　　“需要我停下吗？”
　　梁成敏快要落泪了。栾明睿这么谨小慎微，哪里还像他。于是将他推倒。
　　狂风骤雨拍在他们身上，令他们无比畅快。
　　栾明睿觉得自己闯过了一关。
　　第二天对孩子就格外温柔。过了百天的孩子终于不像个小老头了，也不像小猴子了，竟然有一点好看了。
　　两个人并排坐在那看孩子哼哧哼哧啃手，啃的自己唧唧歪歪，就彼此看一眼，叹口气。
　　“妈，栾明睿小时候这样吗？”梁成敏问婆婆。她见过同事家的小孩，可不是念念这样的。人家百天大的孩子一逗就咯咯乐，哪像念念？象征性呵呵一声，又把笑脸收回去，好像别人都很愚蠢。再看这会儿，没人招没人惹，啃手把自己啃急了。
　　“一个孩子一个样。明睿小时候好像不像念念这么爱着急。”
　　“那就是像你。”栾明睿终于逮到机会，将孩子的怪脾气归咎到梁成敏头上。
　　“胡说道，我妈说我小时候可乖巧了，抱出去这个捏一下那个亲一口，我从来不着急。哪像念念，谁碰都不行。”
　　念念是不许任何邻里碰的。
　　他不是害怕，就是不让碰，你一碰他，他就小脸涨红的生气。这是什么性格啊！
　　没准儿大点就好了呢！
　　梁成敏一心一意都在医学和孩子身上，栾明睿被排到了第三。
　　渐渐的栾明睿就心生了不满。他开始跟孩子吃醋。
　　“你这样不对。”
　　“怎么不对？”
　　“你是要跟我过一辈子的。”栾明睿跟梁成敏讲道理：“你得觉得我最重要。”
　　“你现在拉屎尿尿得用人看着吗？用人喂奶吗？”
　　“拉屎尿尿不用看，喂奶么…倒也行。”
　　梁成敏腾的红了脸：“你走开！”
　　梁成敏尽管让他走开，却也意识到栾明睿吃醋了，于是常常在夜里哄他。两个人都喜欢这件事，每次都格外认真。身体舒畅，心情就更好。
　　梁成敏被栾明睿滋养成了一朵花。
　　从前的她，是小城里头一号厉害的女人，年纪轻轻的外科医生，大家想起她都是她在诊室里认真看病，都忽略了她也是一个女人；现在的她走在小城里，别人都会想：这么好看的女人是谁啊？呦，这不是医院的梁医生吗？梁医生结婚了的，嫁的是栾家的栾明睿。看看梁医生，嫁对了人就更加好看了呢！
　　梁成敏偶尔听到两句议论，都装作没听见红着脸过去。
　　到孩子快一岁的时候，已经会走两步了。梁成敏发现，只要在外面走路，他摔倒了都不会站起来，而是去拍身上的灰。他哪里会拍，于是又开始着急；碰到泥泞的地方，他永远不肯走；手上沾了东西，一定要马上洗掉；衣服脏一点，就自己扯，闹着要换；还有，他不喜欢玩具破损。
　　梁成敏意识到自己的孩子可能不是别人家那些讨人喜欢的小孩，他有那么一点不一样。于是她和栾明睿沟通了很久，他们决定永远不因为他生活习惯上的这些严苛指责他，适当引导他，但不强迫他。
　　他们的努力只有一丁点效果。
　　念念第一次真正打架是在三岁多的时候。正在跟小朋友玩，因为别人抢他玩具，他突然动起了手。小孩子打架，从来都是象征性的你挠我一下，我推你一下，没什么伤害性。可念念骑到了别的孩子身上抓人家脸，这可把梁成敏吓坏了，上前把正在生气的他强行抱走，对人说：“教教孩子，别随便抢别人玩具。我家孩子下手狠。”
　　梁成敏是害怕的。晚上孩子睡了，她跟栾明睿说起这件事，栾明睿嘴角动了动没讲话。他不敢讲话，孩子这点真的随他了。他从小爱打架，小城里的人教育孩子：离栾明睿远点啊，别惹栾明睿啊。栾明睿觉得男孩子么，好斗正常。梁成敏不这样觉得，下手太狠了，像是在逞凶斗勇。
　　她开始抽空看儿童心理学和行为学的籍，开始系统研究孩子的行为。她知道，她的孩子有一点暴力倾向，有强迫症表现。
　　呵护这样一个孩子成长究竟要费多少心呢？梁成敏知道的，栾明睿也知道。他们两个人，为此费尽心力。
　　到了80年代末，栾明睿想去美国。栾家有很多远亲早些年就去了美国，几十年未见，但这些年渐渐恢复了联系。他跟梁成敏商量，如果她不想去，他也就不去。梁成敏不反对，她想去美国继续学习深造，想搞医学研究。于是两个人开始了没日没夜的学习，语言、风俗、习惯，也带着栾念一起学习。
　　离开祖国那天，梁成敏对栾明睿说：“我还要回来的。我要好好搞医学研究，为祖国和人类做贡献。”
　　“那我只能好好赚钱，支持你搞医学研究了。”
　　他们开启新的生活，但从没放弃过彼此。起初的日子很难，但他们每天晚上躺在一起回顾这一天，彼此鼓励。慢慢的日子就好过。梁成敏继续深造，然后进到了课题组开始正式搞医学研究。
　　栾明睿面对的世界充满诱惑，但他从不动摇。
　　他们一辈子只谈过一次恋爱，只爱过一个人，跟这一个人白头到老。
　　他们都不觉得遗憾。
