# 第144章 番外十:念桃

尚之桃怀孕的时候胖很快。
　　到孕中期的时候近140斤了。她个子高,又长了这么多体重，看着就比从前壮了很多。
　　产检的时候医生会批评她：“你是不是吃的很多？要控制啊，再这么下去孩子长的很大,你就要剖腹产了啊！得负责任！”
　　孕期激素水平变化大,平常挺坚强的女人，被医生训了几句出了诊室就哭了。栾念看她哭就问她：“怎么了？”
　　她抽抽嗒嗒说了医生的话，也带着委屈：“你知道的，我吃的不多，也健康,每天也走路。那孩子长的快我有什么办法呢？”
　　她也不懂，林春儿、宵妹、lumi,还有贺云,她们怀孕的时候都只是肚子大,胳膊腿还是那么细细的，看起来很好看。她就要这么狼狈。
　　也问过梁医生,梁医生说：“体质不一样，你这样也很好。多可爱。”
　　梁医生和大翟并不关心尚之桃好看不好看，她们关心她健康不健康。说到底尚之桃要孩子要的晚,再过几年就要变成高龄产妇了。所以梁医生为尚之桃专门配了一个食谱,叮嘱大翟和栾念按食谱给她吃。既能保证解馋,又能控制孕期的血压和血糖。
　　尚之桃怀孕之后变成了国宝，认识的每一个人都照顾她。在公司里，sunny每天计算她工作的时间，超过一个小时就让她下楼走走。公司里的每一个小朋友都变成她遛弯儿的小搭档,轮流陪她下楼透气。在家里,所有人都让着她。
　　她觉得什么都顺心,除了自己长胖这件事。被医生批评了心情就不好,心情不好就会怪栾念：“都怪你！”
　　…
　　栾念哼了一声，拿出纸巾给她擦鼻涕：“丢不丢人？”
　　“丢什么人！”尚之桃泪水汹涌，又拿纸巾擦眼泪：“我现在又胖又丑。”
　　“那你真是多虑了。”栾念指出她话中的问题：“你只是胖，不丑。”
　　栾念讲的倒是实话，尚之桃现在看起来非常棒，肚子隆起，又剪了初恋头，看起来清清爽爽，像只可爱的企鹅。他这句实话要气死尚之桃了，本来还是啜泣，突然之间哇的一声哭了。医院里人来人往，很多人扭头看那个可爱的孕妇站在她老公面前哭。
　　栾念哄了半天才把她哄好，两个人回到家里，尚之桃躺倒在沙发上闷闷不乐。
　　“要不要吃点东西？”
　　“不要，我不配。”
　　“你不吃我女儿还得吃呢！”
　　尚之桃一听更来气了，就坐起身来数落他：“我知道我为什么体重涨这么快了！就因为你！你一周在家里四天，每天都不停的问我吃不吃东西！跟喂猪一样！”
　　“你不在的时候我吃的很健康，无奈你在的时候我吃东西的频率太高了…”
　　“还有，你做饭为什么要那么好吃？你随便做做行不行？你做的难吃我是不是就少吃了？”
　　“那你到底吃的是多是少！”栾念终于忍不住问她。尚之桃顿了顿，当没听见，又继续数落他。
　　数落很久。
　　栾念心情好任她数落，偶尔忍不住了就对她说：“我可以做，你可以选择不吃。”
　　尚之桃气的对他瞪眼睛，他用力捏她脸。
　　孕期的尚之桃像一颗熟透的桃子，栾念觉得自己跟换了一个妻子一样。有时看她圆脸儿红扑扑的就忍不住捏。但她尽管大着肚子，却只是在家里的时候瘫着。出了家门就变成一贯的姿态，站坐都端正。
　　栾念觉得女人真是有奇怪的自我约束力。
　　他在的时候就自己照顾她，不在的时候就由大翟老尚来。尚之桃尽管怀孕了对工作也没有松懈，除了比从前下班早那么一点，因为她要回家睡觉，她非常嗜睡。其余时候就还跟从前一样。
　　栾念心疼她劳累，但她自己开心，跟同伴们一起工作让她觉得快乐。
　　月龄再大一点，尚之桃拉着栾念去拍孕妇照。栾念不愿配合，像从前一样嫌弃。尚之桃对他立眼睛，他终于肯单膝跪地，亲吻她的肚子。
　　小念桃出生那天，尚之桃正在见客户。
　　她过了预产期五天还不出生，也没有征兆。尚之桃就跟着小朋友去见大客户了。在客户那里相谈甚欢，电子版合同发过去，客户那边准备请款走流程，尚之桃起身跟客户握手，突然察觉身下有一股热流。
　　她破水了。
　　于是找了个地方半躺着打了120。
　　栾念刚下飞机，回家取待产包就去了医院。他生平第一次发现自己会手抖。
　　在去往医院的路上，他的手一直在抖。
　　大翟给他吃定心丸：“人好着呢，别担心，已经开指了。”
　　“好的，谢谢。”
　　栾念去到医院，疫情期间不许陪产，他没法见到尚之桃。只能给她打电话，电话接通了，听到尚之桃忍着疼痛说了声喂。栾念问她疼不疼，一个铁骨铮铮的汉子突然就哭了。他抹了把眼底的泪，对尚之桃说：“我就在外面，我陪着你。”
　　尚之桃听到栾念哽咽，就红了眼睛：“那你说爱我。”
　　“我爱你。”
　　“那你叫老婆。”
　　“老婆。”
　　“那你说老婆我爱你。”尚之桃又开始宫缩，她说不下去了，挂断电话前听到栾念说：“老婆，我爱你。”
　　这下栾念不觉得肉麻了。恨不能把所有尚之桃喜欢听的话都说给她听，只要她能舒服那么一点。
　　栾念一直站在那里，老人们都有点紧张。轮流劝他坐下，他都不为所动。尚之桃生孩子生了多久，他就站了多久。当他看到虚弱的尚之桃，眼睛又红了。
　　有宝宝是一件很奇妙的事。
　　尚之桃不想休息，让栾念把小念桃抱给她看。栾念没抱过小孩，僵硬着抱着小念桃，她那么小，闭着眼睛睡觉，他一颗心都要化了。指尖轻轻触在她脸上，婴儿的皮肤太过柔软细嫩，像触在棉花上。栾念觉得自己的心从来没这么柔软过。
　　“我觉得小念桃有点像你。”栾念蹲在尚之桃的床前，将小念桃放到她手边。两个人看着小念桃，甚至舍不得眨眼。
　　尚之桃看看小念桃，再看栾念，突然觉得栾念刚刚就是在胡说道。小念桃分明就是他的翻版。尚之桃不满意了，我辛辛苦苦怀胎十月，费了好大劲儿把你生下来，你竟然一点不像我，跟你爹一个样儿？
　　“你刚刚说她有点像我，哪里像？”尚之桃问栾念。
　　栾念仔细想了想，脸上有那么一点得意，敷衍的十分明显：“你看她的…耳朵，多像你。头发也挺像。”
　　小念桃的头发黑油油的，非常浓密，感觉别人在妈妈肚子里都在努力变好看，而她在努力长头发，努力方向错了。再看她的耳朵，还没长开呢！什么人呐！
　　两个人都盯着孩子，尚之桃说：“怎么会有这么又丑又可爱的人儿啊…”
　　“你说谁丑？”栾念有点不开心：“哪里丑？”
　　护士来赶过两次，栾念都赖着不肯走，最后一次护士威胁他：“再不走明天不许来了啊！”这才离开。他不放心，走之前又去确认护工陪床的事，又担心尚之桃侧切了太疼，就叮嘱护工好好照顾她。
　　出了医院坐在车里很久很久都没有启动车。这一天像做梦一样。
　　栾念有那么一点激动，迫切想跟人分享点什么，就在朋友群里说：“我做爸爸了。我也有了一个女儿。”
　　谭勉手快，迅速发起视频通话，大家陆续接起。栾念最后一个接入，眼睛还红着。
　　几个人都愣了一愣，宋秋寒问他：“你哭了？”
　　栾念没有讲话，过了一会儿，点点头：“是。”
　　“猛汉落泪？”谭勉仔细看了看他的眼：“我没看错？”
　　“不丢人不丢人，哥几个哪个做爸爸没哭过啊？哦不对，谭勉没做过爸爸。”都这个时候了，陈宽年依然不忘揶揄别人。
　　“滚。”谭勉让他滚：“照片呢？小念桃的照片。”
　　栾念发给他们，说：“我基因太强大了。”这会儿尚之桃不在旁边，栾念终于光明正大承认小念桃真是哪里都像他。
　　大家都仔细看，还真的是，跟栾念一个模子扒下来的。
　　“说一下感受。”宋秋寒采访他。
　　“感受就是，人生太他妈好了。跟爱的人结婚，如果都愿意，就要一个孩子。这种感觉特别好。比以往经历的任何事都要好。”
　　“好的，兄弟。你的感言我们听到了。”陈宽年打趣道，又问他：“尚之桃女士怎么样？”
　　“她有一点累。”
　　“我们明天就到。”谭勉说。
　　“不用，等她出院。不然你们也只能匆匆看一眼她和念桃。”
　　“那我们五天后到。”
　　“好。”
　　栾念不敢回家，怕万一有什么事找不到他，就坐在车里听歌。怕尚之桃觉得孤独，就给她发消息：“我就在医院的停车场里，你不要害怕，有什么事我很快就到。”
　　“我能有什么事？你回去睡觉。”
　　“不。”栾念回她，过一会儿又对她说：“尚之桃，辛苦了。谢谢你。”
　　“不辛苦，栾念。后面照顾孩子都归你。”
　　“好。”
　　“你知道吗？我今天特别开心。又心疼又开心，我从前竟是不知道人是这么矛盾。”栾念说。
　　“我对今天很满意，除了念桃不像我。”
　　“没事，长大了神情可以像你。”
　　“？说的是人话？”
　　栾念笑出声来，翻出一家三口的合照来看。尚之桃的脸有一点浮肿，他的唇印在她额头，小念桃在睡觉；还有他们三个人的手，拳头凑在一起。这些从前栾念懒得拍不愿拍的照片，今天拍起来那么自然，他不觉得不自在，甚至很喜欢，特别喜欢。
　　生活在他面前铺陈一幅新的画卷，这回栾念仔细看了。
　　这画卷很美，几乎囊括他对生活所有的美好想象。
