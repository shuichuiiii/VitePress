# 第143章 番外九:念桃

栾念是从什么时候起想做爸爸的呢？大概是陈宽年那个孙子每天都在群里发孩子照片,还挺可爱。
　　栾念从前对孩子没有概念，他甚至觉得不婚不育多好，一个人自在。可现在他的想法变了。有时他睁眼,看到尚之桃的睡颜,就觉得有个孩子似乎也挺好。
　　他准备认真跟尚之桃谈谈。
　　他在他们于桌上完成一场激烈的仪式后，在他们的体内还残留着温情、慵懒之时问尚之桃：“生个孩子怎么样？”
　　尚之桃震惊的看着他：“你戒烟戒酒真是因为这个？”
　　“我为了长命百岁。”栾念胡说道。
　　尚之桃坐起身来看着他。
　　“可是前提是我们应该做负责任的父母。”尚之桃很认真的表达观点。
　　“你连饭都不会做，做一个好妈妈的确差点意思。”栾念嘲讽她，见她要急，又慢悠悠说道：“我会做,我可以补齐你的短板。”
　　尚之桃要被栾念气死了，她踢出一脚,被他抓住脚踝：“现在就开始？”
　　“什么？”
　　“造人。”
　　栾念将她扯坐在怀里,两个人在沙发上对望。外面的大雨拍打在窗上,拍的尚之桃一颗心乱七糟。
　　“我不允许我的小孩家庭不完整，不允许爸爸妈妈不相爱,不允许爸爸妈妈不爱她…”尚之桃这样说。
　　“所以？你有离婚打算？别做梦了尚之桃。”栾念手扣在她脑后，将她拉向他：“你离一个试试？”
　　“不是，我…”
　　栾念堵她的唇,难得温柔。唇贴着唇,舌尖探进去又出来,扫过她唇角：“你了解我的，我只有不想做，没有做不好。”
　　手滑进她的t恤，尚之桃跌在他怀里,轻轻吐出一个字：“好。”
　　抱紧他的脖颈,感受他慢慢的融入,又突然用力。
　　这是他们之间第一次没做措施。尚之桃与lumi聊起过,栾念这样不管不顾的人，却从来都要做措施。这种感觉很奇妙，好像比从前近了很多很多，再也没有缝隙。
　　两个人都有额外的热情，说不清为什么。期间他们滑坐到地上，那一下真的要了尚之桃的命，她哼了一声，像被什么夺走呼吸。
　　这场性/爱像外面那场雨，时而热烈，时而缠绵。栾念亮黑的眼在黑暗中锁着她视线，偶尔见她蹙眉或声音变了，就会问她：“喜欢这样？嗯？”
　　他在探索她。
　　他对尚之桃充满探索的热情。他无法忍受跟她在一个空间里什么都不做，他最喜欢像现在这样随心所欲。他更讨厌房事变的程序化，他的创造力让他推陈出新，他有信心在他六七十岁的时候还能像一个色胚一样跟尚之桃这样。可能那时不会这么激烈，但他心底的热情还在。
　　尚之桃把自己完全交给他，她无比信任他。但这也太漫长了一点。
　　原来造人这么磨人。
　　尚之桃心想。
　　他们闹到天幕黑透。
　　雨还在下，尚之桃找了一面墙倒立。
　　“你做什么？”
　　“说是这样更容易。”
　　“你有病吧？用得着你倒立吗？”栾念将她拉下来：“脑子里装的什么乱七糟的。”
　　他劈头盖脸训了尚之桃一顿，训着训着自己憋不住了，笑了一声，手用力揉了揉尚之桃脑袋，说了一句：“出息！”
　　起身给她和卢克都弄口吃的。
　　在一起的时候是这样，分开以后又是另外一样。
　　栾念赶周二的早班机，走的时候天还黑着。尚之桃还在睡觉，他亲她脸颊，突然间有一点舍不得离开她。
　　尚之桃拉着他手，呢喃一句：“注意安全。”
　　“好。”
　　“早点回来。”拉着他的手贴在自己脸上，栾念心软了软，又说：“好。”
　　到北京径直去公司，在过道看着肚子微微隆起的lumi：“你怀孕了？”
　　lumi朝他挑挑眉：“怎么样？快您一步，是不是有那么一点不服？”
　　栾念撇了撇嘴，耸耸肩，想损她一句，想起她跟尚之桃的关系。就难得对她笑笑：“最近跟flora联系了？”
